 # Python project

**Banking Management System**

**Project Overview**

• The Banking Management System is a Python-based console application developed to manage essential banking operations through a structured and efficient workflow. The system handles customer account management, deposits, withdrawals, fund transfers, and transaction tracking.
• Customer and transaction data are maintained using CSV files, providing structured and persistent data storage without requiring an external database.

**Key Features**

• Account Management – Create and manage Savings and Current accounts.
• Unique Account ID – Automatically generates a unique ID for every account.
• Account Validation – Validates customer name, phone number, and account details.
• Deposit Management – Processes deposits and updates account balances.
• Withdrawal Management – Processes withdrawals with sufficient-balance validation.
• Fund Transfer – Transfers funds between valid accounts with sender/receiver verification.
• Transaction Tracking – Maintains transaction details including ID, type, amount, and date.
• Account Search – Retrieves customer and transaction information using Account ID.
• Data Validation – Prevents invalid inputs and unsuccessful transactions.


**Technology Stack**

• Python – Application Development
• CSV – Data Storage & Management
• UUID – Unique ID Generation
• Datetime – Transaction Date Management
• OS Module – File & Directory Operations

**Core Python Concepts**

• File Handling
• CSV Processing
• Lists 
• Dictionaries 
• Loops 
• Conditional Statements 
• Exception Handling 
• Input Validation 
• Data Processing


 **Project Objective**
 
• The objective of this project is to demonstrate practical implementation of Python programming, file handling, data validation, account management, and           transaction processing by developing a real-world banking application.
• The system can be further enhanced with MySQL database integration, authentication, security features, and a web-based interface.
